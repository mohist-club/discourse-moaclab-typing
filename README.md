# Moaclab Typing

一个安装到 Discourse 的 Theme Component，通过 `/typing` 进入打字练习页面。页面路由由轻量配套插件 `discourse-moaclab-tools` 注册；侧栏入口默认不自动添加，可通过组件开关或 Discourse 后台导航菜单维护。

## 2.6.0

- 输入错误恢复为照常接收：光标继续前进，错字标红加下划线，可用退格改正；改正后不再标记。
- 该打空格时按了字母，在词尾显示红色短线。
- 准确率旁显示错误次数，成绩弹窗增加“错误”一栏；错误次数按按键累计，退格改正的也计入。
- 新增敲击特效：光标每次命中挤压回弹；气势较高时光标滑走留下渐隐残影；无错完成一个词时汉字上跳闪光并迸出火花；flow 到 ×10/25/50/100… 时在光标上方飘出连击数；按错键时光标闪红并抖动。前两类跟随“拼音跃动”开关，残影与连击数跟随“气势”开关，系统“减少动态效果”时全部关闭。
- 2.5.0 的滑动光标、当前词底色与 overdrive 保持不变。

## 词库

- “全部”：3,000 个按词频筛选的 2–4 字词组
- “基础”：其中 HSK 1–2 级词组
- “常用”：其中 HSK 1–5 级词组
- “键盘”：Moaclab 的机械键盘领域词组
- 中文词库与拼音完全离线运行，不请求第三方 API

公开词库来源与许可见 `THIRD_PARTY_NOTICES.md`。如需在未来重新生成，下载上游
`complete.min.json` 后运行：

```sh
node scripts/build-hsk-wordlist.mjs complete.min.json
```

## 安装

1. 先安装并重建 `discourse-moaclab-tools` 路由插件。已有可访问的 `/typing` 路由时不需要重复安装。
2. Discourse 管理后台 → 自定义 → 主题 → 安装 → 从 Git 仓库安装。
3. 输入 `https://github.com/mohist-club/discourse-moaclab-typing.git`，将组件加入当前启用的主题。
4. 如需侧栏入口，可在 Discourse 后台导航菜单中添加 `/typing`；也可开启组件的 `show_sidebar_link`，二者不要同时启用。
5. 清理浏览器缓存后访问 `/typing` 验证页面。

从旧 ZIP 版本迁移时，请先记下原组件设置，再安装 Git 版本。将旧组件从当前主题移除后挂载新组件，避免两个版本同时运行。之后在组件管理页检查更新并拉取即可，不再需要上传 ZIP。推送 GitHub 不等于站点已经更新。

## 开发验证

使用 Node.js 22，运行 `npm ci` 和 `npm test` 检查词库、元数据、SCSS 与 JavaScript。
`npm run preview:build` 会生成隔离预览文件，预览仅模拟路由挂载，不替代真实 Discourse 兼容性验证。

界面、词库、成绩与输入逻辑全部位于 Theme Component；配套插件仅注册真实路由，不增加数据库迁移或额外 API。成绩保存在当前浏览器；如果未来需要跨设备排行榜，应升级为带后端数据表的 Discourse Plugin。
